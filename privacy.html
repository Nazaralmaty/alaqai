Политика конфиденциальности

Алақай делает мультики для детей на казахском и русском и выкладывает их на свои каналы в YouTube, Instagram и TikTok. Для этого есть программа Alaqai Publisher.

Что получает программа

В Alaqai Publisher входит только владелец каналов Алақай. Программа получает одно право: загружать видео и обложки на канал, под которым он вошёл. Данные зрителей, комментарии и чужие аккаунты она не читает.

Где хранятся ключи доступа

Ключи лежат в закрытом файле на компьютере владельца и никому не передаются. Отозвать доступ можно в любой момент на myaccount.google.com/permissions.

Имена детей в заказанных мультиках

Для мультика на заказ вы присылаете нам имена детей в WhatsApp. Мы используем их только для этого мультика и удаляем по вашей просьбе.

Google и YouTube

Программа работает через YouTube API Services. Действуют условия YouTube и политика конфиденциальности Google. Данные, полученные через API Google, используются по правилам Google API Services User Data Policy, включая требования Limited Use.

Privacy policy

Alaqai makes cartoons for children in Kazakh and Russian and publishes them on its own YouTube, Instagram and TikTok channels using a tool called Alaqai Publisher.

Access. Only the owner of the Alaqai channels signs in to Alaqai Publisher. It gets one permission: uploading videos and thumbnails to the channel that signed in. It does not read viewer data, comments or anyone else's account.

Storage. Access tokens stay in a private file on the owner's computer and are shared with no one. Access can be revoked at any time at myaccount.google.com/permissions.

Children's names in ordered cartoons. For a custom cartoon you send us the children's names by WhatsApp. We use them only for that cartoon and delete them on request.

Google and YouTube. The tool uses YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy apply. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
